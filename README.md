  
OWASP Juice Shop - VAPT Practice

About the Project
I used OWASP Juice Shop in my local lab to understand how web applications work and to practice basic security testing.

 Objective
To learn how login requests, HTTP communication and cookies work in a web application.

1.Environment
- Kali Linux
- Docker
- OWASP Juice Shop
- 127.0.0.1:3000

2. Tools
- Nmap
- Firefox Developer Tools
- Docker

3. What I Did
- Set up OWASP Juice Shop using Docker.
- Checked the application port using Nmap.
- Tested the login page and observed the server response.
- Checked GET and POST requests.
- Looked at HTTP request and response headers.
- Checked the cookies used by the application.

4. What I Learned
- Basic HTTP communication.
- Login request and response handling.
- HTTP headers and status codes.
- Cookie attributes and their purpose.
- Basic web application testing.

 Status
Learning and Practicing
This project helped me understand how a web application works behind the browser I also got some practical experience with Nmap, Docker and browser developer tools.
